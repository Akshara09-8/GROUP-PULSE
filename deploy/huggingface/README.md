# Group Pulse API

Backend for the Group Pulse demo: estimates who is looked at most, who disengages and how much rapport a small group has, from gaze and body orientation in meeting video. API docs at `/docs`.

Source: https://github.com/Akshara09-8/GROUP-PULSE. Demo data: AMI Meeting Corpus (CC BY 4.0). Uploaded videos are deleted after 24 hours; scores are estimates, not judgements of people.
